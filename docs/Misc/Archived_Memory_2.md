# Archived Memory 2: To Feel The Stars

![[AM2_KeyArt.png]]
> AM2's official key art.

**Archived Memory 2: To Feel The Stars** (also referred to simply as **AM2**) is an upcoming follow-up to [[Archived Memory 1]], slated for release on August 23, 2026. It was announced at the end of the [[Smithed Summit#2026 Panel|2026 Smithed Summit Drehmal Panel]] on August 21, 2026. 

It is set in part of [[Sahd]], sometime after the events of Archived Memory 1.
